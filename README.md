# ウォーハンマー40,000：ローグトレーダー 日本語再翻訳MOD（RTJP）

『Warhammer 40,000: Rogue Trader』の日本語を、英語原文から訳し直したMODです。
公式訳を手直しするのではなく、会話・地の文・選択肢・能力説明を一から訳し直しています。
翻訳と校正にはAIを使い、実機でも確認しています。Windows向けです。

## ダウンロード

**[v0.1.4 のMOD用ZIPをダウンロード](https://github.com/kumakiti300-stack/rogue-trader-japanese-mod/releases/download/v0.1.4/rogue-trader-japanese-0.1.4.zip)**

- 対応バージョン: ゲーム **1.6.1.514**（Steam Build 24257885）
- 「Source code」ではなく、上のZIPを使ってください
- チェックサム（.zip.sha256）がリリースに添付されています

## 特徴

- 収録文字列は約7.6万件。まだ訳し直していない箇所は、既存の公式日本語がそのまま表示されます（部分差し替え式）
- 用語は「GW公式訳を土台に、40k固有用語は音写し、システム用語は機能訳」の方針で統一しています → [翻訳方針](docs/translation-policy.md)
- 変更した用語は全1,815項目を公開しています → [用語データベース](docs/terminology.md) ／ 変更サンプルは [訳の変更例](docs/guide.md)

## 入れ方

[導入手順](docs/install.md)は、ModFinder RTを使う場合と手動で入れる場合に分けています。ZIP内のREADMEにも同じ手順があります。

**タイトル画面で「次へ」が「コンティニュー」になっていれば、導入成功です。**

## 注意

- AI翻訳のため、誤訳が残っている可能性があります
- 全分岐の動作確認は終わっていません
- 公式日本語とMODの表記が混ざるのは仕様です（未対応箇所は公式訳が表示されるため）

## 改変について

気に入らない訳は、好きに直して使ってOKです。連絡や確認はいりません。
