# Rogue Trader 日本語再翻訳MOD

『Warhammer 40,000: Rogue Trader』の日本語を見直す非公式MODです。
英語原文から、会話・地の文・選択肢・能力説明を訳し直しています。

現在は非公開で、試験版をReleaseの下書きとして準備しています。一般配布はまだ行っていません。

- [Releases一覧](https://github.com/kumakiti300-stack/rogue-trader-japanese-mod/releases)

配布時はReleasesに添付するZIPを使ってください。「Code → Download ZIP」や自動生成の「Source code」には、翻訳ファイルを含めません。

部分的な差し替えで、未修正箇所にはゲームの既存日本語が表示されます。
AIによる翻訳・校正を行っており、人間による全文校正と全分岐のプレイ確認は完了していません。
