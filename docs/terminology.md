# 用語の読み替え早見表

[翻訳方針と変更サンプル](guide.md)

公式訳から表記を変えた主な17項目です。詳細な戦闘ルールや人物名の一覧は含めていません。

| 英語 | ゲーム公式訳 | MOD表記 |
|---|---|---|
| Warrior | ファイター | ウォリアー |
| Operative | オペレーター | オペレーティブ |
| Master Tactician | 戦略の達人 | 戦術の達人 |
| Exemplar | 模範者 | エグゼンプラー |
| Weapon Skill | 武器スキル | 接近戦技能 |
| Ballistic Skill | 弾道スキル | 射撃技能 |
| Perception | 認知力 | 知覚力 |
| Carouse | 身体作用体制 / 身体作用耐性 | 身体耐性 |
| Medicae（技能名） | メディケア | 医術 |
| Momentum | 推進力 | 戦意 |
| Deflection | ディフレクション | ダメージ軽減値 |
| Iconoclast | 革新主義 | 偶像破壊主義 |
| Psyker | 異能者 | サイカー |
| Jae Heydari / Jae | ジェイ・ヘイダリ / ジェイ | ジャイ・ヘイダリ／ジャイ |
| Medusae | メデューサ | メデュサエ |
| Servitude Imperpituis | 不眠奉仕の刑 | 永久奉仕刑 |
| Hypersonic Attack | 超音速攻撃 | 極超音速攻撃 |

Perceptionの「知覚力」は能力値、Awarenessの「認識力」はスキルです。
Medicaeの技能名・判定・計算式は「医術」です。人物・施設・器具などの世界観用語は「メディカエ」とし、Medicae Officerは「メディカエ士官」、medicae deckは「メディカエ・デッキ」と訳し分けます。
「永久奉仕刑」は、自我を奪いサーヴィターとして奉仕させる刑の内容に基づく訳です。
