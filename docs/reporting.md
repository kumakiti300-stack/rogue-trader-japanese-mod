# 気になる訳・表示の報告

報告は、このリポジトリの「Issues」から「翻訳・表示の問題」を選んでください。
言い回し、人物の口調、選択肢の意味、能力の効果や条件、用語の表記揺れ、文字の欠けなどを受け付けます。

## 報告に必要な情報

- ゲームとMODのバージョン。試験版やバージョン不明の場合は、その旨を書いてください。
- 章・場所・会話相手。会話以外なら、画面・アイテム・能力などの名前。
- 実際に表示された文章。
- 気になった点、意味を取りにくかった箇所、表示の問題。

直前に選んだ選択肢や前後の会話、スクリーンショットがあると、場面を探しやすくなります。訳案はなくても構いません。
表示の問題では、併用しているフォント・翻訳MODの名前もあると助かります。

人物の生死や物語の結末など、重大なネタバレはタイトルに書かず、本文に入れてください。
セーブデータやログ一式を添付する必要はありません。
